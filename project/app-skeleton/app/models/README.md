# app/models

SQLAlchemy models yang merefleksikan `database/schema.sql`. Kalau menambah kolom/tabel baru, update KEDUANYA (schema.sql dan model di sini) plus tulis migration script (lihat catatan Definition of Done di Solo Delivery Plan Bagian 8).

Lihat `database/ERD.md` untuk penjelasan tiap entity dan relasinya sebelum menambah model baru di sini.
